# Changelog

All notable changes will be documented here, following Keep a Changelog.
The project uses Go module versioning and is currently an unreleased v0 API.

## [Unreleased]

### Added

- Agent guide, bilingual PIX Mono / PIX Mono Bold fonts under OFL-1.1,
  JSON font loading API/CLI and a text example.

- Public Go module with portable protocol/media codecs and desktop BLE adapter.
- Synthetic protocol/media tests, examples and protocol evidence documentation.
- CI and publication safety checks; MIT license and provenance notices.
- Cancellable multi-packet uploads and an original demonstration font.

### Changed

- Application-extracted fonts and private research inputs excluded from public distribution.
