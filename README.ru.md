PIX Backpack — рюкзаки с программируемым LED-дисплеем, которым изначально управляли
через мобильное приложение. Цель проекта - сохранить локальное управление устройствами и
знания о протоколе, после закрытия компании производителя в январе 2022 года. Облачная учётная запись не требуется.
Проект независимый и не связан с PIX.

Код проекта целиком создан с помощью AI — см. [пояснение и отказ от гарантий](#ai-и-ответственность).

## Возможности

- Платформонезависимое кодирование RGB-палитры и команд с синтетическими тестовыми векторами.
- Импорт PNG/JPEG/GIF точного размера и анимаций `.pixpack`; явное преобразование цветов в WebSafe.
- Загрузка анимаций до 254 кадров, частичные обновления Live и потоковое воспроизведение с отменой через context.
- Бегущая строка с пользовательскими символами 8×20 и встроенными PIX Mono / PIX Mono Bold для русского и английского языков.
- Часы, обратный отсчёт, секундомер, велоиндикаторы и управление встроенными играми; змейка и игральный кубик.
- CLI для поиска устройств, чтения характеристик, показа изображений, трассировки и экспорта коллекций.

Тест проводился на реальном рюкзаке PIX Original V1 с прошивкой 2.5.1 и экраном 16×20,
подключённом к macOS Apple Silicon. Управление играми, другие прошивки и Mini
остаются экспериментальными. Сохранение после перезапуска питания, декодирование
RPC-ответов, OTA и управление PIN не проверены или не реализованы.

## Установка

```sh
go get github.com/temamagic/pix-backpack-go
```

Требуется Go 1.25 или новее — это минимальная версия для закреплённой зависимости
Bluetooth.

## Быстрый старт

Пример формирует пакеты команд без Bluetooth и ресурсов оригинальных приложений:

```go
package main

import (
    "fmt"
    "github.com/temamagic/pix-backpack-go/pix"
)

type packets struct{}
func (packets) Write(p []byte) (int, error) {
    fmt.Printf("%x\n", p)
    return len(p), nil
}

func main() {
    animation := pix.Animation{Width: 1, Height: 1, Frames: []pix.Frame{
        {Pixels: []pix.RGB{{R: 255}}, Duration: 300},
    }}
    if err := pix.NewClient(packets{}).Upload(animation, 1, false); err != nil {
        panic(err)
    }
}
```

Для работы с рюкзаком на macOS установите Go и Xcode Command Line Tools,
предоставьте доступ к Bluetooth, затем клонируйте репозиторий и соберите CLI
со встроенными метаданными разрешения Bluetooth:

```sh
git clone https://github.com/temamagic/pix-backpack-go.git
cd pix-backpack-go
./build.sh pixctl
./bin/pixctl scan
./bin/pixctl info -device 'ИМЯ_ИЛИ_АДРЕС_УСТРОЙСТВА'
./bin/pixctl show -device 'ИМЯ_ИЛИ_АДРЕС_УСТРОЙСТВА' picture.png
./bin/pixctl text -device 'ИМЯ_ИЛИ_АДРЕС_УСТРОЙСТВА' 'PIX'
```

Изображение должно соответствовать размерам экрана, прочитанным с устройства.
По умолчанию `show` загружает данные в RAM. Флаг `-save` явно запрашивает запись
во flash; сохранность после отключения питания не подтверждена. Перед подключением
отключите мобильное приложение от рюкзака. Трассы могут содержать ваши изображения,
а результаты сканирования — идентификаторы устройств; удаляйте их перед публикацией.

## Шрифты и текст на двух языках

`mono` (по умолчанию) и `mono-bold` поддерживают печатные ASCII-символы, русские
буквы с Ё/ё, цифры и №. Это адаптации Terminus в формат 8×20 с лицензией
[SIL OFL 1.1](pix/fonts/OFL.txt); [источник и преобразование](pix/fonts/README.md).
Собственный небольшой `demo` также доступен. Извлечённые из приложений шрифты исключены.

```sh
./bin/pixctl text -font mono 'Hello, PIX! Привет, мир! Ёжик 123'
./bin/pixctl text -font mono-bold 'Hello! Привет!'
./bin/pixctl text -font-file my-font.json 'My text / Мой текст'
./bin/pixctl font-license
```

Если найдено несколько рюкзаков, выберите нужный через `-device`. В Go используйте
`pix.LoadFont(path)` или `pix.ReadFont(reader)`, затем передайте результат в
`ScrollText`. [Руководство по шрифтам](docs/fonts.md) описывает JSON, pixpack и примеры.

## Совместимость

BLE на macOS использует CoreBluetooth, CGO и Xcode Command Line Tools.
Аппаратные наблюдения доступны для Apple Silicon. Сборка macOS Intel проверена,
но работа с физическим Intel Mac — нет. Linux/BlueZ и Windows/WinRT остаются
экспериментальными: успешная сборка не подтверждает передачу BLE-пакетов на устройстве.
Пакет `pix` доступен независимо от BLE; на неподдерживаемых платформах пакет `ble`
возвращает `ErrUnsupportedPlatform`.

## Сохранение устройств

Для исследования использовались предоставленные владельцем материалы Android- и
iOS-приложений и локальные BLE-эксперименты. Проект сохраняет знания о протоколе и
реализацию локального управления существующими устройствами. `.pixpack` — формат
обмена данными приложений, отдельный от BLE RPC.

[Аккаунт бывшего производителя](https://www.instagram.com/pix.backpack/) приведён
как исторический источник. Проект не распространяет оригинальные приложения,
декомпилированный код, извлечённые из приложений шрифты или коллекции анимаций.
